# Zain Ventures India website

The one-page site at https://www.zainventures.in. It shows two services: the daily Rourkela ⇄ Patna AC bus, and bus and car hire.

## Files

- `index.html` — the whole page, with the CSS inline. No JavaScript, no web fonts.
- `logo.webp` — the logo on the page. `logo.png` and `logo-96.png` are for the favicon, the manifest and social previews.
- `site.webmanifest`, `sitemap.xml`, `robots.txt`, `llms.txt`, `CNAME` — site metadata.

## Preview

Open `index.html` in a browser.

## Deploy

GitHub Pages publishes the `gh-pages` branch. A push to `gh-pages` updates the live site in a few minutes.
